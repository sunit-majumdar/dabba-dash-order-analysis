# Dabba Dash Orders - Data Dictionary

> **SYNTHETIC DATA.** Dabba Dash is a fictional food-delivery company. Every row was generated by a script (see `generator/`). No real company data is used or implied.

**What it is:** an order log export for a fictional 10-minute-style food delivery company in six Indian cities, 1 January 2025 to 30 June 2026. One row per order, as exported from the order system.

**File:** `dabba_dash_orders.csv`

| Column | Type as exported | Meaning |
|---|---|---|
| `order_id` | text | Order reference, e.g. DD100001 |
| `order_date` | text | Date the order was placed, written DD-MM-YYYY |
| `order_time` | text | Time the order was placed, HH:MM (24-hour) |
| `city` | text | City the order was delivered in |
| `cuisine` | text | Restaurant cuisine category |
| `customer_type` | text | New or Returning customer |
| `payment_method` | text | UPI, Card, COD (cash on delivery) or Wallet |
| `order_value_inr` | number | Basket value in rupees, before delivery fee |
| `discount_pct` | number | Discount applied to the order, in percent |
| `delivery_fee_inr` | number | Delivery fee charged, in rupees (0 = free delivery) |
| `distance_km` | number | Restaurant-to-customer distance in kilometres |
| `delivery_time_min` | number | Minutes from order placed to delivered |
| `rating` | number | Customer rating from 1 to 5 |
| `status` | text | Delivered or Cancelled |
